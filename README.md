# UNFILED.

Interactive scrapbook-inspired portfolio prototype for illustrations, digital projects, creative writing, and worldbuilding.

## Project files

- `index.html`: page structure and scrapbook composition
- `styles.css`: textures, layouts, animations, and responsive design
- `app.js`: routing, filters, modals, reading views, and sample content
- `assets/grain.png`: local background grain
- `CREDITS.md`: third-party material credits

## Development

Open `index.html` in a browser, or serve locally with `python -m http.server 8000`.

The `main` branch is connected to Vercel at https://ammar-portofolio-jude-fa28.vercel.app. Commits to `main` trigger deployments automatically.

## Current limitations

This is a prototype using sample content. Contact postcards only preview and copy, and are not emailed. Admin CMS, authentication, and Supabase storage are not yet implemented. Some decoration is still loaded from third-party URLs and needs an internet connection.
